### 1.1 作业管理模块

#### TC-FUNC-001: 创建作业

| 属性 | 值 |
|------|-----|
| **ID** | TC-FUNC-001 |
| **模块** | 作业管理 |
| **优先级** | P0 |
| **类型** | 功能测试 |

**前置条件**:
- 用户已登录且角色为老师
- 学生列表已存在

**测试步骤**:
1. 进入作业列表页
2. 点击"添加作业"按钮
3. 填写作业标题 (必填)
4. 选择科目 (必填)
5. 设置截止日期 (必填)
6. 选择学生 (必填)
7. 填写作业描述 (可选)
8. 点击"提交"

**预期结果**:
- 作业创建成功
- 显示成功提示
- 作业列表中出现新作业
- 作业状态为"未开始"

**测试数据**:
```json
{
  "title": "数学练习第 3 章",
  "description": "完成课后习题 1-10",
  "subject": "数学",
  "deadline": "2026-03-25 23:59:59",
  "student_id": 1
}
```

## 2. API 测试用例

### 2.1 认证 API

#### TC-API-001: 登录 API - 成功场景

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "username": "testuser",
  "password": "password123"
}
```

**预期响应**:
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "role": "teacher"
  }
}
```

**断言**:
- 状态码 200
- 返回 token
- 返回用户信息

---

#### TC-API-002: 登录 API - 密码错误

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "username": "testuser",
  "password": "wrongpassword"
}
```

**预期响应**:
```json
{
  "error": "用户名或密码错误"
}
```

**断言**:
- 状态码 401
- 错误信息正确

---

#### TC-API-003: 登录 API - 用户不存在

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "username": "nonexistent",
  "password": "password123"
}
```

**预期响应**:
```json
{
  "error": "用户名或密码错误"
}
```

**断言**:
- 状态码 401

---

#### TC-API-004: 注册 API - 成功场景

```http
POST /api/v1/auth/register
Content-Type: application/json

{
  "username": "newuser",
  "email": "newuser@example.com",
  "password": "password123",
  "role": "teacher"
}
```

**预期响应**:
- 状态码 200
- 返回 token 和用户信息

---

#### TC-API-005: 注册 API - 用户名重复

```http
POST /api/v1/auth/register
Content-Type: application/json

{
  "username": "existinguser",
  "email": "unique@example.com",
  "password": "password123",
  "role": "teacher"
}
```

**预期响应**:
```json
{
  "error": "用户名或邮箱已被注册"
}
```

**断言**:
- 状态码 409

---

#### TC-API-006: 注册 API - 邮箱格式无效

```http

```

- 参数验证错误

#### TC-API-007: 注册 API - 密码过短
