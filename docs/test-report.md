### 4.2 严重 Bug

#### BUG-001: JWT 密钥硬编码

| 属性 | 值 |
|------|-----|
| **ID** | BUG-001 |
| **严重程度** | 🔴 Critical |
| **模块** | 认证 (auth.go) |
| **类型** | 安全漏洞 |

**问题描述**:
在 `auth.go` 的 `generateToken` 函数中，JWT 密钥有硬编码的默认值：

```go
secret := os.Getenv("JWT_SECRET")
if secret == "" {
    secret = "edu-assistant-secret-key-2026"  // ⚠️ 硬编码密钥
}
```

**风险**:
- 生产环境如果未设置环境变量，将使用已知密钥
- 攻击者可以伪造任意 token
- 严重的安全漏洞

**修复建议**:
```go
secret := os.Getenv("JWT_SECRET")
if secret == "" {
    log.Fatal("JWT_SECRET environment variable is required")
}
```

**状态**: ⏳ 待修复

---

#### BUG-002: 密码加密成本过低

| 属性 | 值 |
|------|-----|
| **ID** | BUG-002 |
| **严重程度** | 🔴 Critical |
| **模块** | 用户模型 (user.go) |
| **类型** | 安全漏洞 |

**问题描述**:
在 `user.go` 中使用 `bcrypt.DefaultCost`，默认值为 10，对于生产环境可能过低：

```go
hashedPassword, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
```

**风险**:
- 密码哈希容易被暴力破解
- 不符合现代安全标准

**修复建议**:
```go
// 使用更高的成本因子 (12-14 推荐)
const BcryptCost = 12
hashedPassword, err := bcrypt.GenerateFromPassword([]byte(password), BcryptCost)
```

**状态**: ⏳ 待修复
