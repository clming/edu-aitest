## 📋 项目概览

**项目名称**: EduAssistant (教育助手)

**项目定位**: 跨平台个性化学习辅助应用

**目标平台**:
- 📱 iOS (14+)
- 🤖 Android (10+)
- 🌐 Web (Chrome/Safari/Edge)

**技术栈**:
- **前端**: Flutter 3.x
- **后端**: Go 1.21+
- **数据库**: PostgreSQL 15+ / Redis 7+
- **网关**: OpenClaw Gateway

---

## 🎯 核心功能

1. **课程管理**: 课程浏览、章节学习、进度追踪
2. **学习工具**: 笔记、收藏、错题本
3. **AI 助手**: 智能问答、学习建议、个性化推荐
4. **数据统计**: 学习统计、成就系统、学习报告
5. **通知提醒**: 推送通知、学习提醒、消息中心
