## 2. 家长用户故事

### 2.1 账户管理

#### US-P-001: 注册账号
```yaml
ID: US-P-001
标题: 注册家长账号
角色: 家长 (新用户)
优先级: P0
模块: 个人中心

故事:
  作为 一名新家长
  我想要 快速注册账号
  以便于 开始使用教育助手

验收标准:
  - [ ] 输入手机号后能收到验证码
  - [ ] 验证码验证通过后能设置密码
  - [ ] 选择家长角色后能填写孩子信息
  - [ ] 注册成功后自动登录
  - [ ] 整个流程不超过 3 分钟

依赖: 无
估算: 3 天
```

### 7.1 Given-When-Then 格式

```gherkin
功能：作业查看
  场景：家长查看今日作业
    Given 家长已登录账号
    And 孩子有今日作业
    When 家长打开 APP 首页
    Then 显示今日作业卡片
    And 显示作业科目和数量
    And 点击卡片能查看作业详情

  场景：家长查看历史作业
    Given 家长已登录账号
    When 家长点击"查看全部"
    And 选择日期筛选
    Then 显示对应日期的作业列表
```
