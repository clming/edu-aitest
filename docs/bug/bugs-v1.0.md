### BUG-001: JWT 密钥硬编码

| 属性 | 值 |
|------|-----|
| **发现版本** | v1.0 |
| **修复版本** | v1.1 |
| **严重程度** | 🔴 Critical |
| **优先级** | P0 |
| **模块** | 认证 (auth.go) |
| **状态** | ✅ 已修复 |

**问题**: JWT 密钥硬编码导致安全风险  
**影响**: 攻击者可伪造任意用户 token
