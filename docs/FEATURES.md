## 2. 作业管理模块

### 2.1 功能列表

#### HW-001: 作业查看
| 属性 | 描述 |
|------|------|
| **优先级** | P0 |
| **端** | iOS / Android / Web |
| **用户角色** | 家长、学生 |
| **预估工时** | 3 天 |

**功能描述**:
查看老师布置的作业详情，包括题目、要求、截止时间、提交状态等。

**详细需求**:
- [ ] 首页展示今日作业卡片 (科目、数量、截止状态)
- [ ] 作业列表页，支持筛选 (日期、科目、状态)
- [ ] 作业详情页展示完整信息
- [ ] 支持查看历史作业
- [ ] 作业状态标识 (未开始/进行中/已提交/已批改)

**UI 元素**:
- 作业卡片 (科目图标、作业标题、截止时间、状态标签)
- 筛选器 (日期选择器、科目下拉框、状态下拉框)
- 作业详情区 (题目描述、附件、提交入口)

**接口需求**:
- `GET /api/v1/homeworks` - 获取作业列表
- `GET /api/v1/homeworks/{id}` - 获取作业详情

#### HW-002: 作业提交
| 属性 | 描述 |
|------|------|
| **优先级** | P0 |
| **端** | iOS / Android |
| **用户角色** | 学生、家长 |
| **预估工时** | 5 天 |

**功能描述**:
通过拍照或相册选择的方式提交作业，支持多张图片。

**详细需求**:
- [ ] 调用相机拍照
- [ ] 从相册选择图片
- [ ] 支持多张图片 (最多 9 张)
- [ ] 图片预览和删除
- [ ] 图片顺序调整
- [ ] 添加文字备注 (可选)
- [ ] 提交确认
- [ ] 提交成功反馈

**UI 元素**:
- 拍照按钮
- 相册选择按钮

- 删除按钮 (每张图片)
- 备注输入框

**接口需求**:
- `POST /api/v1/homeworks/{id}/submit` - 提交作业
- `POST /api/v1/upload/image` - 上传图片

**技术要点**:
- 图片压缩 (目标<500KB)
- 图片格式转换 (统一 JPG)
- 上传进度显示
- 断点续传 (大文件)
