## 1. 设计原则

### 1.1 核心设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                    教育助手设计原则                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🔹 简洁清晰 (Simple & Clear)                               │
│     - 减少认知负担，一屏一任务                              │
│     - 信息层级清晰，重点突出                                │
│     - 文案简洁易懂，避免专业术语                            │
│                                                             │
│  🔹 温暖友好 (Warm & Friendly)                              │
│     - 圆润的视觉元素，减少尖锐感                            │
│     - 温暖的色彩搭配，营造安全感                            │
│     - 亲切的文案语气，像朋友一样                            │
│                                                             │
│  🔹 高效便捷 (Efficient & Convenient)                       │
│     - 常用功能触手可及 (3 次点击内)                          │
│     - 智能预判用户需求                                      │
│     - 减少输入，多用选择                                    │
│                                                             │
│  🔹 可信可靠 (Trustworthy & Reliable)                       │
│     - 数据展示准确清晰                                      │
│     - 操作反馈及时明确                                      │
│     - 隐私保护 visibly                                      │
│                                                             │
│  🔹 激励有趣 (Motivating & Engaging)                        │
│     - 游戏化元素适度融入                                    │
│     - 正向反馈及时给予                                      │
│     - 进步可视化展示                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 设计禁忌

| ❌ 不要 | ✅ 要 |
|--------|------|
| 信息过载，一屏太多内容 | 留白充足，呼吸感强 |
| 冷冰冰的机器语言 | 温暖的人文关怀语气 |
| 复杂的操作流程 | 简单直观的交互 |
| 刺眼的高饱和度色彩 | 柔和的中低饱和度色彩 |
| 尖锐的直角和棱角 | 圆润的圆角和曲线 |
| 负面批评的语气 | 正向鼓励的表达 |

## 2. 设计风格

### 2.1 整体风格定位

**风格关键词**: `温暖` `简洁` `专业` `活力`

```
教育助手 UI 风格 = 现代扁平 + 温暖圆角 + 教育活力
```

### 2.2 设计参考

| 参考应用 | 借鉴点 | 差异化 |
|---------|--------|--------|
| 作业帮家长版 | 信息架构清晰 | 更温暖、更少商业化 |
| 小猿口算 | 操作简洁 | 更多情感化设计 |
| ClassDojo | 游戏化激励 | 更克制、更教育化 |
| 钉钉 | 家校沟通 | 更轻量、更聚焦 |

## 4. 字体系统

### 4.1 字体家族

```
中文优先：
- iOS: PingFang SC (苹方)
- Android: Noto Sans SC (思源黑体)
- Web: PingFang SC, Noto Sans SC, sans-serif

英文/数字：
- iOS: SF Pro Text
- Android: Roboto
- Web: -apple-system, BlinkMacSystemFont, sans-serif
```

### 4.2 字号规范

```

┌──────────────────────────────────────────────┐

│                                              │

│  ████  例："作业详情"                        │
│                                              │
└──────────────────────────────────────────────┘

正文字号
┌──────────────────────────────────────────────┐
│                                              │
│  Body  16px  主要正文                         │

字号使用规则:
- 同一屏不超过 3 种字号

```

### 4.3 字重规范

```
┌──────────────────────────────────────────────┐

│  Bold  700  强调文字、按钮文字                │
│  ████                                         │

│  ████                                         │
│                                              │
```

### 4.4 行高规范

```
行高 = 字号 × 行高系数

标题：字号 × 1.3  (紧凑)
正文：字号 × 1.5  (舒适)
注释：字号 × 1.4  (适中)

示例:
- H1 28px → 行高 36px
- Body 16px → 行高 24px
- Caption 12px → 行高 17px
```
